# 空间记忆模块 MVP — 设计文档

**日期**: 2026-07-13
**状态**: 已批准

## 1. 空间记忆卡片

### 1.1 首页混合
- 首页 LazyColumn 同时展示时间记忆和空间记忆
- 空间卡片复用现有玻璃质感卡片样式
- 左边色条: **橙色 (#F59E0B)** — 区分于 Meeting蓝 / Onsite绿 / QualityTime紫
- 卡片标注 "空间记忆"
- 显示: 标题 / 质量 / 日期

### 1.2 导航
- 点击空间卡片 → SpaceDetailScreen（已有，显示 3D 模型 + 查询）
- "我的" → "空间库" 入口保留

### 1.3 后台变动
- listMemories API 需要同时返回 time_memories + space_memories
- MemorySummary 新增 type 字段 (TIME/SPACE)

## 2. 3D 模型渲染
- 复用现有 Model3DViewer（WebView + Google `<model-viewer>`）
- 加载后台产出的 glb 模型，支持旋转/缩放
- 无模型时显示 "模型生成中…"

## 3. 照片质量实时反馈

### 3.1 分析位置
- **手机端分析**: JPEG 模糊度、平均亮度
- **IMU 分析**: 陀螺仪角速度（已有 IMU 通路）

### 3.2 反馈通路
```
眼镜拍照 → 手机 onImageReceived → JPEG分析
眼镜 IMU → 手机 parseImuSample → 陀螺仪分析
                                  ↓
                            综合判断:
                            - 模糊 → "画面模糊，请保持稳定"
                            - 暗光 → "光线不足"
                            - 过快 → "请慢一点移动"
                                  ↓
                            rk_custom_client → 眼镜显示
```

### 3.3 检测阈值
| 检测项 | 方法 | 阈值 |
|--------|------|------|
| 模糊 | Laplacian 方差 (OpenCV for Android) | < 50 触发 |
| 暗光 | 平均灰度值 | < 60 触发 |
| 运动过快 | 陀螺仪角速度绝对值和 | > 1.5 rad/s 触发 |

### 3.4 反馈策略
- 合格时不提示（安静通过）
- 不合格时眼镜显示对应文案，持续 2 秒或直到下一帧合格
- 反馈频率限制: 同一类型最多每 3 秒提示一次
